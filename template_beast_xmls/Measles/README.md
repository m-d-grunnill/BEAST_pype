# Template Measles xmls for beast_pype

This directory is for developing template BEAST 2 xmls for analysing measles on BEAT_pype.



The chain lengths and storage options are set to the defaults of 10,000,000 and 10,000 (respectively).

Descitpion of model priors for these are found in [Description_of_priors_in_templates.ipynb](Description_of_priors_in_templates.ipynb).

## BDSKY-serial template for BDSKY-Serial workflow.
File: BDKSY-Serial.xml

## Coalescent exponential template for generic workflow.
File: Measles_coalescent_exp.xml
